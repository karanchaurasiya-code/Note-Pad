# Notepad Web Application
A Simple and Responsive Note-Taking App using HTML, CSS, and JavaScript

This project is a lightweight and user-friendly notepad web application developed using HTML, CSS, and JavaScript. The application allows users to create, edit, and delete notes directly in the browser. It utilizes the browser's Local Storage  to store notes persistently, ensuring that user data remains intact even after refreshing or closing the browser.

Key Features:

Create, edit, and delete notes with ease

Real-time saving of content using Local Storage

Responsive and clean user interface

No backend or external database required

Works offline in modern web browsers
